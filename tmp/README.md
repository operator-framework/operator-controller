# GA API shape — review copies

This directory holds Go API type definitions for reviewing the proposed GA
API shape. The first files are verbatim copies of the current definitions
from `api/v1`; subsequent commits apply the proposed GA shape so each kind's
changes can be reviewed as a diff.

This directory is for review only and will not be merged. The files rely
only on the unchanged `groupversion_info.go` boilerplate.
